Accesso limitato ai soli dati dell'app

MediaHub richiede l'autorizzazione drive.appdata, lo scope Google più ristretto disponibile per Drive: dà accesso esclusivamente a una cartella nascosta e dedicata all'app (l'"App Data Folder"), invisibile nell'interfaccia normale di Google Drive.

L'app non può vedere, leggere o modificare nessun altro file presente nel tuo Google Drive: non i tuoi documenti, non le tue foto, non le cartelle condivise.

Puoi revocare l'accesso in qualsiasi momento dalla pagina Autorizzazioni del tuo Account Google.
